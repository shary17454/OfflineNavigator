Offline Navigator

الدعم والمساعدة

البدء

امنح التطبيق إذن الوصول إلى الموقع، ثم اضغط «Save Current» لحفظ إحداثياتك الحالية. اختر نقطة محفوظة لفتح شاشة الخريطة وعرض المسافة وسهم الاتجاه.

الملاحة دون اتصال

اختر رمز الشبكة أعلى شاشة الخريطة لاستخدام Offline Grid. تبقى الإحداثيات والمسافة والاتجاه والبوصلة والتنبيه متاحة دون اتصال، بينما قد تحتاج خريطة Apple إلى الإنترنت.

ملفات GPX والمشاركة

يمكن استيراد ملفات GPX من تطبيق الملفات، وتصدير النقاط المحفوظة ومشاركتها عبر AirDrop أو واتساب أو أي تطبيق يظهر في ورقة المشاركة.

حل المشكلات

  • إذا لم يظهر الموقع، افتح إعدادات iOS واسمح للتطبيق باستخدام الموقع أثناء الاستخدام.
  • إذا كان اتجاه البوصلة غير دقيق، حرّك الهاتف بشكل الرقم 8 وابتعد عن المعادن والمجالات المغناطيسية.
  • يتطلب النسخ الاحتياطي تسجيل الدخول إلى iCloud وتمكينه على الجهاز.

التواصل

للبلاغات الفنية، افتح مشكلة في مستودع GitHub مع وصف الجهاز وإصدار iOS وخطوات تكرار المشكلة.
