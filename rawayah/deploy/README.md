# حزمة النشر — موروث

كل ملف هنا دليل تنفيذي جاهز خطوة بخطوة. اقرأ بالترتيب:

1. **اختر استضافة واحدة**:
   - `RAILWAY_DEPLOY.md` — الأسهل، موصى به للإطلاق الأول (~$15-25/شهر)
   - `RENDER_DEPLOY.md` — بديل مشابه (~$38/شهر)
   - `VPS_DEPLOY.md` — الأرخص طويل المدى، يحتاج خبرة سيرفرات (~$12-30/شهر)
2. `DOMAIN_HTTPS.md` — بعد اختيار الاستضافة، اربط الدومين
3. `APPLE_DEVELOPER.md` — بالتوازي أو بعدها، إعداد النشر على App Store

## ما الذي تغيّر في الكود لدعم هذا؟

**إصلاح CORS في `apps/api/src/main.ts`**: الخادم كان بلا CORS مفعّل إطلاقًا — لو الموقع العام (`your-domain.com`) استدعى الـAPI من دومين مختلف (`api.your-domain.com`)، كان المتصفح سيرفض كل الطلبات. الآن مضبوط عبر متغير بيئة جديد:

```
ALLOWED_ORIGINS=https://your-domain.com,https://admin.your-domain.com
```

غيابه = وضع تطوير محلي (كل الأصول مسموحة) — لا يكسر أي شيء محليًا، لكن **إلزامي وضعه في الإنتاج**.
