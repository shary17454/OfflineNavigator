# Apple Developer + App Store Connect — دليل تنفيذي كامل

هذا القسم الوحيد الذي **يستحيل** تنفيذ جزء منه إلا يدك أنت — يشمل توقيع هوية قانونية وتحقق شخصي. كل خطوة فيها ما أقدر أساعد فيه محدد بوضوح.

## الخطوة 1 — حساب Apple ID (لو ما عندك واحد مخصص للتطبيق)
1. https://appleid.apple.com → **Create Your Apple ID**
2. يفضّل بريد مخصص للنشاط (لا بريدك الشخصي اليومي) حتى يسهل تسليم الحساب لاحقًا لو احتجت
3. فعّل **Two-Factor Authentication** إجباريًا — Apple لا تسمح بالتسجيل في Developer Program بدونها

**ما لا أقدر أسويه هنا:** إدخال بياناتك الشخصية، رقم هاتفك، والتحقق بالرمز المُرسل لجهازك.

## الخطوة 2 — التسجيل في Apple Developer Program
1. https://developer.apple.com/programs → **Enroll**
2. اختر نوع الحساب:
   - **Individual (فرد)**: أسرع (يوم واحد عادة)، الاسم الظاهر في الستور هو اسمك الشخصي
   - **Organization (مؤسسة)**: يحتاج D-U-N-S Number (رقم تعريف تجاري) — أبطأ (أسبوع لأسابيع) لكن الاسم الظاهر هو اسم شركتك/مشروعك
3. الرسوم: **$99/سنة** — تُدفع من بطاقتك مباشرة لأبل
4. لو اخترت Organization: تحتاج إثبات قانوني أنك مخوّل بالتوقيع باسم المؤسسة

**ما لا أقدر أسويه هنا:** الدفع، وتوقيع "Apple Developer Program License Agreement" — عقد قانوني بين Apple وبينك شخصيًا كمالك المحتوى ومسؤول عنه أمام القانون. لا يمكن لأي طرف ثالث (بشري أو آلي) التوقيع نيابة عنك.

## الخطوة 3 — إعداد App Store Connect
بعد قبول العضوية (تصلك رسالة تأكيد من Apple):
1. https://appstoreconnect.apple.com → **My Apps → +  → New App**
2. **Platform**: iOS
3. **Name**: موروث (تحقق أولًا أن الاسم غير محجوز — لو محجوز، جرّب "موروث - Mawrooth" أو صيغة مشابهة)
4. **Primary Language**: Arabic
5. **Bundle ID**: من القائمة المنسدلة اختر `com.shary17454.rawaya` — **يجب تسجيله أولًا** في **Certificates, Identifiers & Profiles → Identifiers → +** قبل ما يظهر هنا
6. **SKU**: أي معرّف داخلي فريد، مثلًا `mawrooth-ios-001`

## الخطوة 4 — التوقيع (Signing) — من جهازك عبر Xcode
هذا الجزء أقدر أساعدك فيه لو أعطيتني وصول لتشغيل الأوامر، لكن تسجيل الدخول بحسابك في Xcode لازم يدك أنت:
1. افتح `apps/mobile/ios/Runner.xcworkspace` في Xcode
2. **Xcode → Settings → Accounts → +** → سجّل دخولك بـ Apple ID الخاص بالمطور
3. اختر target **Runner → Signing & Capabilities**
4. فعّل **Automatically manage signing**، واختر **Team** الخاص بحسابك
5. Xcode ينشئ شهادة التوزيع (Distribution Certificate) و**Provisioning Profile** تلقائيًا

## الخطوة 5 — البناء والأرشفة (أقدر أنفذ هذا الجزء بأوامر Bash)
**تذكير من تفضيلاتك المحفوظة: الأرشفة دائمًا عبر Xcode الرسمي (Product → Archive)، لا نسخة beta — وإلا يُرفض الرفع بخطأ ITMS-90111.**

```bash
cd apps/mobile
flutter build ipa --release \
  --dart-define=API_BASE_URL=https://api.your-domain.com/api
```
هذا ينتج ملف `.ipa` في `build/ios/ipa/`. أو بديلًا عبر Xcode مباشرة:
1. Xcode → اختر **Any iOS Device** كوجهة (لا محاكي)
2. **Product → Archive**
3. بعد اكتمال الأرشفة: نافذة **Organizer** تفتح تلقائيًا → **Distribute App → App Store Connect → Upload**

## الخطوة 6 — بيانات الصفحة في App Store Connect
هذا الجزء يحتاج قرارات محتوى منك، وأقدر أساعدك بصياغة النصوص لو حددت التوجه:
- **وصف التطبيق** (حتى 4000 حرف بالعربي)
- **الكلمات المفتاحية** (100 حرف، مفصولة بفواصل)
- **لقطات الشاشة**: مطلوبة لكل حجم (6.7" و6.5" و5.5" على الأقل) — أقدر أنتجها من المحاكي بنفس الطريقة اللي جهزنا فيها screenshots سابقًا
- **رابط سياسة الخصوصية**: `https://your-domain.com/privacy` (الصفحة موجودة فعلًا في `apps/web/pages`)
- **الفئة العمرية (Age Rating)**: استبيان من Apple يحدد التصنيف تلقائيًا حسب إجاباتك
- **الفئة (Category)**: Reference أو Education غالبًا الأنسب لمحتوى تراثي

## الخطوة 7 — الإرسال للمراجعة
1. بعد رفع الـ build ورؤيته في **TestFlight** (تلقائي بعد المعالجة، يأخذ 15-60 دقيقة)
2. من صفحة التطبيق: **App Store → اختر الـ Build → Submit for Review**
3. مدة المراجعة المعتادة: 24-48 ساعة
4. **نقطة رفض شائعة لتطبيقات المحتوى**: تأكد أن تسجيل الدخول التجريبي (Demo Account) متاح في حقل **App Review Information** لو التطبيق يتطلب حسابًا لعرض المحتوى — أضف بيانات حساب اختباري مؤقت هناك.

## قائمة تحقق قبل الإرسال
- [ ] `API_BASE_URL` يشير لخادم إنتاج فعلي (ليس localhost)
- [ ] سياسة الخصوصية منشورة وقابلة للوصول
- [ ] حساب تجريبي جاهز لمراجعي Apple إن لزم
- [ ] لقطات شاشة بكل الأحجام المطلوبة
- [ ] الأرشفة عبر Xcode الرسمي (غير beta)
- [ ] رقم الإصدار في `pubspec.yaml` محدّث (حاليًا `0.1.0+1`)
