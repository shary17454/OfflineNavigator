# رواية

تطبيق iOS بـ SwiftUI لكتابة وقراءة الروايات محليًا على الجهاز، بواجهة عربية واتجاه RTL، دون الحاجة إلى حساب أو اتصال بالإنترنت.

## الميزات

- مكتبة روايات شخصية مع بحث وتصنيف ومفضلة.
- إنشاء وتعديل الروايات (العنوان، المؤلف، النبذة، التصنيف، لون الغلاف).
- فصول متعددة مع إعادة ترتيب وحذف.
- محرر نص مع حفظ تلقائي وعدّاد كلمات عربي.
- قارئ بخيارات حجم الخط وتباعد الأسطر ومظهر نهاري/ليلي/دافئ.
- تصدير الرواية كملف نصي ومشاركتها عبر ورقة المشاركة.
- تخزين محلي بـ Core Data، مع رواية تجريبية عند أول تشغيل.

## البنية

- `Riwaya/`: مصدر التطبيق.
- `RiwayaTests/`: اختبارات إحصاء النص والتصدير.
- `Riwaya.xcodeproj/`: مشروع Xcode.

## البناء والاختبار

افتح `Riwaya.xcodeproj` في Xcode، أو:

```sh
xcodebuild test \
  -project Riwaya.xcodeproj \
  -scheme Riwaya \
  -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro' \
  -derivedDataPath /tmp/RiwayaDerivedData
```

ملاحظة: هذا المستودع يحتوي أيضًا على تطبيق **مدّل** (`OfflineNavigator`) بشكل منفصل؛ مشروع رواية مستقل في `Riwaya.xcodeproj`.
