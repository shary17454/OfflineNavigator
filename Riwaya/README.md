# رواية

تطبيق iOS بـ SwiftUI للكتابة والقراءة **دون اتصال**، مكمّل لمنصة **رواية / Rawaya** التراثية الموجودة في `rawayah/`.

الواجهة عربية RTL، والبيانات محلية على الجهاز عبر Core Data.

## العلاقة مع منصة Codex

- منصة رواية الكاملة (API/Web/Admin/Flutter): `../rawayah/`
- دفتر دون اتصال داخل Flutter يستلهم نفس تجربة هذا التطبيق
- هذا المشروع يبقى خيارًا أصليًا لـ iOS عند العمل بدون خادم

## الميزات

- مكتبة روايات/مساهمات شخصية مع بحث وتصنيف ومفضلة.
- إنشاء وتعديل الأعمال (العنوان، المؤلف، النبذة، التصنيف، لون الغلاف).
- فصول متعددة مع إعادة ترتيب وحذف.
- محرر نص مع حفظ تلقائي وعدّاد كلمات عربي.
- قارئ بخيارات حجم الخط وتباعد الأسطر ومظهر نهاري/ليلي/دافئ.
- تصدير العمل كملف نصي ومشاركته عبر ورقة المشاركة.
- تخزين محلي بـ Core Data، مع مساهمة تجريبية عند أول تشغيل.

## البناء والاختبار

افتح `Riwaya.xcodeproj` في Xcode، أو:

```sh
xcodebuild test \
  -project Riwaya.xcodeproj \
  -scheme Riwaya \
  -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro' \
  -derivedDataPath /tmp/RiwayaDerivedData
```
